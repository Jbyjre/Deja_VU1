How it connects

Your computer runs it. Your browsers open it.

Each printer shares its state with every module through one connection. Physical U1 testing is pending.

Core: Python and a browser. Slicing, camera bridges and private remote access need separate tools. Optional notifications, integrations and update checks contact configured services. Remote access needs protection: there is no app login.
