Away from home

Reach this dashboard through a Cloudflare Tunnel

The dashboard stays on your home network; cloudflared, a separate program you run on the same machine, opens an outgoing link to Cloudflare. The printer itself is never exposed. It needs a domain on Cloudflare and about fifteen minutes of setup — the steps are in docs/remote-access.md. Put Cloudflare Access in front of it: this dashboard has no login of its own.
