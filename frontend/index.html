        Worth knowing: this drives another program from outside. An OrcaSlicer update can change its command line; when that happens a slice here fails with Orca's own message in words — it never quietly makes a bad file. Every slice is checked for real, printable layers before it's added, and records which Orca version made it.

            Size

            Layers

              TD (transmission distance) is how thick a layer must be before it hides what's under it. The numbers start as estimates from each colour's lightness — measure your own filament for the truest result.

              Away from home

              Reach this dashboard through a Cloudflare Tunnel

              The dashboard stays on your home network; cloudflared, a separate program you run on the same machine, opens an outgoing link to Cloudflare. The printer itself is never exposed. It needs a domain on Cloudflare and about fifteen minutes of setup — the steps are in docs/remote-access.md. Put Cloudflare Access in front of it: this dashboard has no login of its own.
