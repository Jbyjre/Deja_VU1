What this report never holds

  • file names or model contents (a file is shown as "file 3, .3mf, 2.4 MB")
  • camera pictures or time-lapse frames
  • IP addresses, host names or printer serial numbers
  • Wi-Fi names
  • API keys or AI sign-ins
  • AI chat text
  • anything typed into a field, except the notes you write with "Something felt off"
  • the contents of the printer's G-code

Anything that looks like an IP address, a key, a Wi-Fi name or a home-folder path is replaced before it is written. events.jsonl in the same zip is the raw record: open it in any text editor to check.

report.json holds the same data for machines (schema_version 1). Made by Deja Vu1's Tester mode.
